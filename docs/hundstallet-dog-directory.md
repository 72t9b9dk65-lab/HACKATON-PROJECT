# Hundstallet dog directory

Snapshot collected on **7 September 2026** from [Hundstallet’s public dog directory](https://hundstallet.se/hundar/).

This document includes all **43 published profiles in the saved dataset**: **41 individual dog profiles** and **2 group profiles**. Group listings may represent multiple dogs, so 43 profiles does not mean 43 individual dogs. Details are in English; dogs’ names and place names retain their original spelling.

These are the details saved during the earlier collection, not a new live check. Ages, locations, and adoption statuses refer to that snapshot and may have changed. The directory does not necessarily include every dog cared for by Hundstallet. A listed shelter is not a live location; “Rehoming team” means that no shelter was assigned in the saved listing.

## Source notes

- Every name links to its official Hundstallet profile. Photograph links point to the source images collected with those profiles.
- Breed labels are the English labels retained in the project’s imported dataset. A mixed-breed description does not establish verified ancestry.
- “Long stay” and “Trial adoption” are the translated statuses retained in that dataset.
- Source file: [Saved directory dataset](../public/data/hundstallet/directory.json).
- Donation transactions, simulated care needs, generated pixel avatars, and hypothetical spending are not included in this directory.
